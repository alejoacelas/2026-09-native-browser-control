while preserving Orca's independent embedded-browser control. This is a personal
exploration and troubleshooting project.

Read README.md and INVESTIGATION.md before working. Use Claude Opus 5.5 as requested.

extension, or integration, and before permanent deletion. Explain the component,
expected benefit, and consequences; wait for explicit approval. Such actions are

configs, tokens, cookies, session transcripts, or private browsing data. Keep only
sanitized findings and reproduction steps here. Commit and push completed work.

Verify native browser tool discovery and actual Chrome control in a fresh Codex
session, plus account-switch/restart persistence and independent Orca browser
operation where feasible. Do not claim an executable handshake proves browser
control. Do not provision the separate Hetzner server as part of this task.
